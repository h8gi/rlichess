# Normalize Game Data (Legacy Alias)

Alias for
[`lic_tidy_games()`](https://h8gi.github.io/rlichess/reference/lic_tidy_games.md)
for backward compatibility.

## Usage

``` r
lic_normalize_games(data, username)
```

## Arguments

- data:

  Raw game tibble.

- username:

  Target username.

## Value

A tidy tibble.
